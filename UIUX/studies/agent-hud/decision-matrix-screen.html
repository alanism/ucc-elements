Recommended mix. Option A's radar for the Eisenhower matrix + Option B's zone strip for the journey, with the difficulty blocks and the tile wall for batches.

Option A — Darkstar radar. Thin-line instrument look (Darkstar 10/19, PR NAV). The Eisenhower matrix is a radar: crosshair axes split the four quadrants, range rings fade outward, tasks are diamond contacts with a "+" size tag, and a dotted route links the do-first order. Timeline/journey is a node track; batch progress is the Tactical Auditorium 30 tile wall.

Option B — Plan view. Filled-zone look (Early Dev 15 / Lopardo plan view). The same matrix as four tinted zone panels with gradient fills and diamond contacts; the timeline is the zone-column strip with a T-clock; difficulty is the amber block grid, light = easy → dark = hard; batch progress is the tile wall.
