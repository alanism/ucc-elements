A control atlas for touch, motion, and state

These controls are designed to be felt before they are understood: dials that turn with weight, switches that settle into place, buttons that press into their sockets, and displays that make state visible.

Every element below is a working interaction study. Change its state, test its keyboard behavior, and reveal the implementation when you want to inspect the pattern behind the surface.

Portable by design. No hosted design service is required. The controls are self-contained, accessible, and ready to adapt.

    // One voice per held key: attack, decay to sustain, release on key up.
function noteOn(midi) {
  const f = 440 * 2 ** ((midi - 69) / 12), t = ctx.currentTime;
  const osc = ctx.createOscillator(); osc.type = "triangle"; osc.frequency.value = f;
  const g = ctx.createGain();
  g.gain.setValueAtTime(0.0001, t);
  g.gain.exponentialRampToValueAtTime(0.22, t + 0.005);   // attack
  g.gain.exponentialRampToValueAtTime(0.09, t + 0.3);     // decay → sustain
  osc.connect(g).connect(master); osc.start();
  voices.set(midi, { osc, g });
}
function noteOff(midi) { const v = voices.get(midi); v.g.gain.setTargetAtTime(0.0001, ctx.currentTime, 0.08); v.osc.stop(ctx.currentTime + 0.5); }

    06.01 / Signal & feedback
    Lumen VU · analog level meter−20 … +3 VU

    A needle with weight. It rises in about 300 ms and settles with a slight overshoot, so a reading feels physical rather than twitchy. Use it for a level, a load or a quota where the trend matters more than the exact digit. The halo knob sets input gain, and its ring dims when the signal is off.

    MINMAX
    −∞ VU · gain 62%
    knob: drag ↕ · ←/→ keys · Home/End · peak lamp holds for 350 ms above 0 VU
    Lumen VU
    // VU scale is logarithmic: 0 VU sits at ~71% of the arc, +3 at 100%.
const vuPos = db => Math.pow(10, db / 20) / Math.pow(10, 3 / 20);
const vuAngle = p => -44 + p * 88;            // degrees either side of 12 o'clock

// Ballistics: an under-damped spring, integrated per frame.
const BALLISTIC = { k: 110, c: 15 };           // ≈300 ms rise, ~1.5% overshoot
function stepNeedle(n, targetDb, dt) {
  const a = -BALLISTIC.k * (n.p - vuPos(targetDb)) - BALLISTIC.c * n.v;
  n.v += a * dt;  n.p += n.v * dt;
  if (n.p > 1.04) { n.p = 1.04; n.v *= -0.3; }   // the pin stop bounces
  needle.setAttribute("transform", `rotate(${vuAngle(n.p)} 110 150)`);
}
