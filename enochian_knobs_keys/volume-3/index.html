Enochian Elements

Compact controls · action and state

Twenty compact controls for direct actions and visible state. Cinnabar carries the signal; Ivory and Obsidian carry the surface.

Each control does one job and shows its state plainly. Every one has an Ivory and an Obsidian finish, spring motion, keyboard access, and a copyable fragment behind the Code Veil.

Same construction. No libraries and no hosted services. The springs, clicks, synth voices and ball physics are all written inline.

Find the right pattern

  • Play notes with the Canticle Keys.
  • Trigger or latch an action with the Triad Action Keys, the Cinnabar Key or the Hollow Gate.
  • Turn something on or off with the Binary, Cinnabar, Beacon, Glyph, Pinch and Pinch Track switches.
  • Set several on/off states side by side with the Triune Switch and the Triune Beacon.
  • Pick a value along a line with the Trackin', Square and Dimpled sliders.
  • Steer in two dimensions with the Sigil Controller.
  • Find anything on this page with Seeker Orb.

    One octave of a pocket synth. Each key is a pill cap set in a square cell, and the accidentals are round caps marked with the signal dot. Hold a key and the note sustains, then fades out when you let go. Several keys can sound at once. Your computer keyboard plays it too once it has focus.

    Canticle Keys
    // One voice per held key: attack, decay to sustain, release on key up.
function noteOn(midi) {
  const f = 440 * 2 ** ((midi - 69) / 12), t = ctx.currentTime;
  const osc = ctx.createOscillator(); osc.type = "triangle"; osc.frequency.value = f;
  const g = ctx.createGain();
  g.gain.setValueAtTime(0.0001, t);
  g.gain.exponentialRampToValueAtTime(0.22, t + 0.005);   // attack
  g.gain.exponentialRampToValueAtTime(0.09, t + 0.3);     // decay → sustain
  osc.connect(g).connect(master); osc.start();
  voices.set(midi, { osc, g });
}
function noteOff(midi) { const v = voices.get(midi); v.g.gain.setTargetAtTime(0.0001, ctx.currentTime, 0.08); v.osc.stop(ctx.currentTime + 0.5); }

    The compact control finish line

    Small controls have the least room to explain themselves, so each one here carries its state in a single cue: a lamp, a colour, a printed symbol, or the depth of a cap. If you have to read the label to know whether something is on, the control hasn't done its job.

    Less, but better, and always legible.
