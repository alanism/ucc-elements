Hands on. Play unlocks local browser audio. Jog by dragging; arrows seek 0.1 s, Page keys 1 s, Home / End reach loop limits. Knobs and faders: arrows adjust, Page keys jump, Home / End limit, double-click resets. Upper pads recall four hot cues; SHIFT sets them at the current position. Lower pads play Kick / Snare / Hat / Clap. Beat Sync matches the other deck’s tempo and approximate phase.
Audio safety. Two deterministic 8-second loops, generated locally. Preview 1 / 2 solos through this same browser output — not a hardware headphone bus. Changing tabs or leaving the window stops every source; return requires an explicit Play. Keep device volume low.
