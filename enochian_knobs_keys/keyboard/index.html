01 / PLAYING & CONNECTION GUIDE

Enable SOUND explicitly. Hold keys with pointer, Space / Enter, or computer keys A W S E D F T G Y H U J K O L P ; ' [ ] = \\ Backspace / Z. Octave and transpose changes release notes safely. Pitch springs to center; modulation holds. Encoders: drag up, arrows, Page Up / Down, Home / End; double-click restores default.

Top pads hold eight chords. Bottom pads select four voices, toggle arpeggio and latch, tap tempo, or release everything. MODE chooses up / down / bounce / random; RATE selects ¼, ⅛, ⅛T, ¹⁄₁₆. LATCH retains released keys until panic. SCALE constrains new notes to C major. ARP uses held pitches and GATE / SWING / TEMPO.

Not connected. MIDI requires browser support and explicit permission; no output is selected automatically.
