Enochian Elements

A control atlas for touch, motion, and state

These controls are designed to be felt before they are understood: dials that turn with weight, switches that settle into place, buttons that press into their sockets, and displays that make state visible.

Every element below is a working interaction study. Change its state, test its keyboard behavior, and reveal the implementation when you want to inspect the pattern behind the surface.

Portable by design. No hosted design service is required. The controls are self-contained, accessible, and ready to adapt.

Find the right pattern

  • Tune a value with a rotary dial.
  • Choose a fixed position with a detented dial or sliding ordinal control.
  • Combine independent states with the Triune Gate.
  • Control playback with the Aether Receiver or Horologion.
  • Measure elapsed time with the Vigil Clock.
  • Type with tactile feedback on the Mechanical Keyboard.
  • Trigger an action with the Push Button or Three Keys.
  • Inspect the construction by opening the Code Veil.
